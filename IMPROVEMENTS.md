# IMPROVEMENTS.md

*Analysis date: 2026-07-11*

Learning Theory Games is a collection of eight standalone HTML/JS educational
games (VC-dimension, Rademacher complexity, overfitting, p-adic Gibbs
regression, CN2, network analysis, P3 recommendations) that auto-deploy to
`learning-theory.arithmetic.guru` via GitHub Actions. The project is healthy
and actively used for teaching, but has some housekeeping debt: untracked
working files (`zubarev.py`, `zubarev.py~`, `zubsample1.csv`), a committed
`index.html` that CI also regenerates, and CDN dependencies that contradict
the "no external dependencies / just download and open" promise in README.md.

## Bugs & Fixes

- **`index.html` is both committed and generated by CI.** The deploy workflow
  (`.github/workflows/deploy.yml`) rebuilds it from README.md with pandoc, so
  the committed copy will silently drift from README (it already predates the
  P3 game commit). Either delete it from git and add to `.gitignore`, or stop
  regenerating in CI. Prefer the former — one source of truth.
- **CDN dependencies break the "standalone" promise.** README says "just
  download one of these HTML files and open it", but
  `rademacher-calculator.html`, `overfitting-explorer.html`,
  `padic-gibbs-explorer.html` and `p3-recommendation-engine.html` reference
  external URLs (Chart.js etc.). Offline/classroom use will fail. Either
  inline/vendor the libraries or amend the README caveat.
- **`zubarev.py` untracked and orphaned.** It implements the Zubarev p-adic
  Gibbs algorithm that `padic-gibbs-explorer.html` is based on, yet it, its
  editor backup `zubarev.py~`, and `zubsample1.csv` are all untracked. Decide:
  commit `zubarev.py` + sample CSV as reference implementation, or delete.
  Delete `zubarev.py~` regardless.

## Improvements

- **Shared style extraction.** Every game duplicates the glassmorphism/dark
  theme CSS inline. Fine for standalone files, but consider a small template
  or a `tools/` lint that checks each game includes the common nav/back-link
  so the site feels coherent.
- **Cross-linking.** Games don't link back to the index page; add a small
  "← All games" header link (relative, so downloaded copies degrade
  gracefully).
- **Next games from TODO.md** — the highest-leverage unstarted items given
  the course context: Cross-Validation Simulator, Regularization Playground,
  and the Multi-Armed Bandits Casino. The Research-Aligned section
  (Ultrametric Distance Explorer) aligns with the maintainer's p-adic ML
  research and would be a distinctive addition.

## Testing

- **No tests at all.** At minimum add a CI smoke test: load each HTML file in
  headless Chromium (Playwright) and assert zero console errors. This would
  catch broken CDN links and JS regressions before deploy. Put it in
  `deploy.yml` as a gate before the SCP step.
- `tools/build_p3_game.py` has no test; a quick check that it emits valid
  HTML containing expected MovieLens node counts would do.

## Documentation

- README.md and index generation are good. Add a one-line note per game on
  which course week it targets (network playground already says "Week 11").
- AGENTS.md is just a header pointing at Codex; either mirror CLAUDE.md's
  content or make it a symlink/pointer so agent guidance doesn't fork.

## Security

- No secrets found in the repo. Deploy uses SCP via GitHub Actions —
  confirm the SSH key in repo secrets is deploy-scoped (write-only to the
  web root), and pin action versions in `deploy.yml`/`claude.yml` to SHAs.
- CDN `<script>` tags have no Subresource Integrity attributes; add
  `integrity=` hashes if you keep the CDN approach.

## Housekeeping / Modernization

- **Python tooling: adopt uv.** `tools/build_p3_game.py` and `zubarev.py`
  (numpy/pandas) should be run via `uv run tools/build_p3_game.py` with deps
  declared in a `pyproject.toml` via `uv add numpy pandas` (or PEP 723 inline
  script metadata, given the repo is HTML-first). Do not introduce
  requirements.txt.
- Add `*.py~`, `*.csv` scratch patterns (or specific files) to `.gitignore`
  to keep `git status` clean.
- TODO.md is well-maintained — keep striking through completed items as the
  single backlog.

## Quick Wins

1. `rm zubarev.py~`; commit or delete `zubarev.py`/`zubsample1.csv`.
2. Remove committed `index.html` from git (CI regenerates it).
3. Add SRI hashes or vendor Chart.js inline.
4. Add a Playwright console-error smoke test to CI.
5. Flesh out AGENTS.md or point it at CLAUDE.md.
